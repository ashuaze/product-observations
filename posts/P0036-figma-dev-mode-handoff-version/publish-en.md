### 1/4

1/4 You start building a date picker from a Figma frame marked Ready for dev. Tomorrow the spacing changes. Should you follow the new design or finish what you started? The handoff needs to tell you which version to build.

### 2/4

2/4 Figma can flag a direct edit to a handed-off frame as Changed. In Dev Mode's focus view, you can compare versions or copy a link to a specific one. That gives the team a way to name what it agreed to build.

### 3/4

3/4 Figma lists a blind spot: changing the value of a variable already applied to a layer won't trigger Changed. The spacing can move while the badge stays put. https://help.figma.com/hc/en-us/articles/26781702258583-Dev-Mode-statuses-and-notifications

### 4/4

4/4 For sign-off, link the agreed version and record any shared values that matter. For fast iteration, use the live frame and agree which edits need a new handoff. Test both with a direct edit and a change to a shared variable.
