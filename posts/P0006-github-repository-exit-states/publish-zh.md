### 1/4

1/4 用户说“我要离开项目”，可能是停止维护、交给别人，或让项目消失。

GitHub 的 Archive、Transfer、Delete 看似相邻，却在解决不同任务。确认弹窗无法替用户选对任务。

### 2/4

2/4 Archive 把仓库变成只读参考资料，仍可搜索和 fork，也能取消归档。Transfer 则让项目在新所有者下继续。

迁移并非全量无损：Pages 链接、权限和套餐能力都需要另行检查。
https://docs.github.com/en/repositories/archiving-a-github-repository/archiving-repositories

### 3/4

3/4 删除的影响还取决于关系：公共仓库删除后 fork 保留，私有仓库的 fork 则会被删除。

部分仓库虽可在 90 天内恢复，fork 网络可能限制自助恢复，团队权限也不会一并回来。

### 4/4

4/4 先定义想得到的结果，再选择暂停、移交、移除或恢复。

恢复窗口不是完整回滚承诺。验收不只看对象有没有回来，也要看当前获准的团队能否继续工作。
