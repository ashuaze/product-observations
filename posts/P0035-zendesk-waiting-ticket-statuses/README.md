# Zendesk 工单：等待中，等的是谁？

- 原期号：P35
- 日期：2026-11-11（北京时间）
- 研究主题：协作交接与责任（P34–P40）
- 读者价值：设计工单等待状态时，分别检查谁该行动、谁负责跟进，以及哪条服务时限继续计。

用同一宗丢件对照 Zendesk 等客户与等承运商的行为。客户提示不同，服务时间也可能算得不同；端到端解决时限则可以把两种等待都纳入。单一状态加明确字段也可能足够。本期核查了官方规则，未实测效率。

关键参考：[工单生命周期](https://support.zendesk.com/hc/en-us/articles/8263915942938-About-the-ticket-lifecycle-and-ticket-statuses)、[客户门户状态](https://support.zendesk.com/hc/en-us/articles/4408825864858-What-are-the-customer-portal-ticket-statuses)、[SLA 定义](https://support.zendesk.com/hc/en-us/articles/4408829459866-Defining-SLA-policies)。
