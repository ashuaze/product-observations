# P46｜TikTok 与 Instagram：推荐重置，该保留什么？

- 原期号：P46；稳定 ID：P0046。
- 日期：2026-11-22（Asia/Shanghai）。
- 研究主题：推荐系统如何判断一次行为是否应该影响未来推荐？P41–P47 周期中的案例对照。
- 本篇读者价值：把重建推断兴趣与审阅主动选择分开设计，并评估恢复过程的成本。

## 观点总结

TikTok 的 2023 年刷新说明保留已启用设置与关注账号；Instagram 的 2024 年重置说明覆盖 Explore、Reels 和 Feed，并给用户审阅关注列表、选择取消关注的机会。两家团队都描述了后续根据新互动继续个性化。

可以借鉴的判断是先辨认修复范围：只有一个话题不合适时，比较局部纠正；整体兴趣陈旧时，再比较广泛重置。保留主动选择能保护仍有价值的关系，但关注也会过时，应让用户决定是否审阅。效果须跨多次使用检验，兼顾不想要的重复、有用发现及恢复操作成本。
