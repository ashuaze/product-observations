# YouTube 不感兴趣：反馈后，哪些页面应该改变？

原期号 P42 · 2026-11-18（北京时间）

**研究主题** 推荐系统如何判断一次行为是否应该影响未来推荐？本期是 P41–P47 周期的第二篇，采用四条短观察。

**读者价值** 为个性化产品定义反馈作用的页面与情境，设计能同时衡量不想要的推荐、有效关联内容和反馈负担的验收方法。

## 观点与证据边界

YouTube 官方说明首页与下一条推荐主要依据不同信号。一篇 2023 年论文中的历史审计显示，同一种反复负反馈在首页与固定视频旁取得不同结果。设计时需决定反馈跨页面的效力，并把当前视频保持或更换作为对照条件。实验设置与当代普通用户情境存在差异，本篇使用它建立测试问题。当前功能事实来自本次核查的官方英文帮助文档。
