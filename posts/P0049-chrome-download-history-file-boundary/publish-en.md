### 1/3

1/3 On desktop Chrome, removing a download from history leaves the saved file on your computer. Clearing download history does too. An empty Downloads page tells you about the record, not whether the files are gone.

https://support.google.com/chrome/answer/2392709?hl=en&co=GENIE.Platform%3DDesktop

### 2/3

2/3 That separation serves a real task: tidy a recent activity list while keeping the work. For disk cleanup, though, it leaves the downloaded files untouched. The useful distinction is which object the user wants removed.

### 3/3

3/3 Chrome's 'Show in folder' helps locate the saved file. That boundary matters in download managers and recent file lists: a log describes an event; storage cleanup acts on a saved file. Name whether an action changes the record, the file, or both.
