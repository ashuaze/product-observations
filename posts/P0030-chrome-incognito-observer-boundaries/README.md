# P30｜Chrome 无痕模式：谁看不到什么，直到什么时候？

日期：2026-11-06（Asia/Shanghai） · 稳定编号 P0030 · 原期号 P30

**研究主题：** 隐私与默认设置（P27–P33）。

**读者价值：** 用 Incognito 与 Guest 的不同任务，核对隐私模式的观察者、清理对象和结束条件。

**观点总结：** 自己临时浏览与把电脑借给别人，需要保留的上下文不同。模式说明应告诉用户什么会清除、什么有意留下，以及谁仍可能观察；用情境预测测试理解。

**证据边界：** 功能规则来自本次打开的 Chrome 英文电脑端文档；研究来自 2018 年美国在线实验，不代表当前用户误解率。本次无设备实测。
