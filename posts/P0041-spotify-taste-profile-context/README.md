# Spotify：一次播放该怎样影响下一次推荐？

原期号 P41 · 2026-11-17（北京时间）

**研究主题** 推荐系统如何判断一次行为是否应该影响未来推荐？本期为 P41–P47 周期的首篇。

**读者价值** 设计个性化产品时，决定应该保留行为、调整行为对未来推荐的影响，还是控制某处显示或播放的内容。

## 观点与证据边界

播放歌单和选择让播放影响推荐是两件可独立处理的事。Spotify 允许用户减弱特定歌单中播放记录的影响，同时保留同一曲目从其他入口播放时产生的信号。歌单作为范围的前提是它能代表相对一致的用途。Spotify 文档支持功能边界和生效时点。实际推荐变化、用户理解和发现质量仍需验证。
