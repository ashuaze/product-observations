# P0015｜Zoom vs Google Meet：免费边界为什么会在会议中途出现？

**日期：** 2026-10-22（Asia/Shanghai）  
**研究主题：** 免费与付费边界  
**稿件状态：** 中英文均为草稿，待人工审稿

比较时长限制的触发时点、决策主体与多人协调成本。

## 观点总结

- 时长上限与入口限制不同：用户能够开始任务，但免费边界可能在多人协作进行中触发。
- Zoom Basic 几乎所有由免费用户主持的会议都限 40 分钟；Google Meet 免费版在电脑端允许双人会议最长 24 小时，从 3 人起限制为 60 分钟。
- 两者免费版都支持最多 100 人，因此差异不只是容量，而是将“持续时间”还是“持续的多人协调”作为付费信号。
- 会议权益由主持人套餐决定，中断成本却由全体参与者承担；应同时观察转化与未完成任务。
- 没有公开因果证据证明这些限制提高了收入或改善会议质量，正文不推断公司意图。
