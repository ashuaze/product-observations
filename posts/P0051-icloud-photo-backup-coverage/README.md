# P51｜iCloud Photos 与设备备份：成功备份覆盖了什么？

- 稳定编号：P0051；原期号：P51
- 日期：2026-11-27（Asia/Shanghai）
- 研究主题：产品如何让用户分清本机副本、同步内容与独立备份？（P48–P54）
- 读者价值：帮助产品经理、设计师与独立开发者按资料类别、功能依赖和事故类型定义备份成功。
- 观点总结：照片同步会改变设备备份的覆盖范围；iPhone 的电脑备份也排除已经同步并存于 iCloud 的照片。备份时间应结合覆盖内容、恢复位置及条件理解。独立导出是额外副本，仍需要更新与检查。
- 证据边界：依据当日可读的 Apple 英语官方文档，区分已同步照片、设备备份和照片导出。没有账号操作或恢复实验；不提供关闭同步即可完整备份的保证。
