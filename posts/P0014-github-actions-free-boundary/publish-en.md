### 1/4

1/4 GitHub Actions has a revealing free-tier boundary: publicness is one of its meters. Standard GitHub-hosted runners are free for public repos; private repos receive plan quotas, with overage billed when paid usage is enabled.

https://docs.github.com/en/billing/concepts/product-billing/github-actions

### 2/4

2/4 One plausible reading: GitHub subsidizes public code because it can attract contributors, reusable Actions and ecosystem activity. But GitHub documents the rule, not that motive. Treat the subsidy logic as a pricing hypothesis, not stated company intent.

### 3/4

3/4 Two guardrails expose the economics. Larger GitHub-hosted runners are billed even for public repos. Self-hosted runners are free in Actions, but the user pays for machines and maintenance. "Free" either stops at premium capacity or moves the cost.

### 4/4

4/4 Decision rule: subsidize baseline use when the output creates ecosystem value; meter scarce capacity separately. But don't use publicness as a universal proxy for willingness to pay: teams with confidential code cannot trade secrecy for a discount.
