# 隐私默认值：沿着数据走四步

- 原期号：P33
- 日期：2026-11-09（北京时间）
- 研究主题：隐私与默认设置（P27–P33 周期综合）
- 读者价值：把隐私默认值的评审落到可重复的检查：权限、查看者、时间和副本路径。

以 Google 相册为起点，沿收集、可见范围、到期触发和副本四处检查。Strava 的公开路段榜说明，限制范围会改变可用任务。比较统一收紧和任务内按需授权时，同时验收接收方实际拿到的内容与任务完成情况。

证据边界：官方文档说明适用条件下的行为；设计比较和验收方法属于编辑推断，未做行为实验或产品实测。关键参考：[Google 相册](https://support.google.com/photos/answer/6153599?hl=en)、[Strava 活动可见性](https://support.strava.com/en-us/articles/15401987-how-do-my-activity-privacy-controls-work-on-strava)、[Android 运行时定位权限](https://developer.android.com/develop/sensors-and-location/location/permissions/runtime)、[Signal 阅后即焚](https://support.signal.org/hc/en-us/articles/360007320771-Set-and-manage-disappearing-messages)。
