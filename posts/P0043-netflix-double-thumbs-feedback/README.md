# Netflix 双赞：多一个反馈选项，什么时候值得？

原期号 P43 · 2026-11-19（北京时间）

**研究主题** 推荐系统如何判断一次行为是否应该影响未来推荐？本期为 P41–P47 周期第三篇，采用四条短观察。

**读者价值** 决定何时增加偏好强度选项，并同时衡量区分能力、推荐价值与反馈参与率。

## 观点与证据边界

2017 年 Netflix 从五星改成赞与踩，2022 年又加入双赞。新增强度能够表达「喜欢」之上的偏好，但对偏好原因仍然留有不确定。团队自报的 2017 年评分活动增长同时伴随选项数量与反馈含义变化。设计判断应落在新增信号的实际价值与参与成本上。当前三个选项由帮助中心核查，历史实验数字为企业自报，本文没有进行账号体验或独立效果实验。
