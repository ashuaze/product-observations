# P0001｜连胜保护：允许多少次中断，才能帮助用户继续？

**日期：** 2026-10-08（Asia/Shanghai）  
**研究主题：** 习惯设计  
**稿件状态：** 中英文均为草稿，待人工审稿

区分记录连续与真实练习，评价容错额度是否帮助用户回来。

## 观点总结

- 功能：提前装备的连胜保护可以覆盖漏学日，使记录保持连续。
- 数值：官方历史文章报告，允许同时装备两个保护后，每日活跃学习者相对增加 0.38%；这是相对变化，不是提升 0.38 个百分点。
- 边界：Jackson Shuttleworth 在 2024 年访谈中回忆，三个保护没有比两个带来更好结果。他将原因解释为“帮助人回来”与“鼓励更长间隔”同时存在。
- 判断：应同时检查中断后的回归、实际练习天数与学习效果。记录连续本身不能证明练习或能力提高，这是本篇提出的评价框架。
- 可信程度：上述产品结果主要来自公司文章与团队访谈，缺少公开的完整实验数据；“三个无额外收益”不能改写成“三个显著有害”，也不能把“两次”当成通用最优数值。
