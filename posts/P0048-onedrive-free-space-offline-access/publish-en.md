### 1/5

1/5 A file can stay visible in Windows File Explorer after its local download is removed. OneDrive's Files On-Demand makes that useful for saving disk space. It also creates a design question: what should a file's presence promise about access?

### 2/5

2/5 In OneDrive for Windows, 'Free up space' makes a file online-only without deleting it from OneDrive. Deleting a synced file removes it from OneDrive online and other synced devices. These actions change different things.

https://support.microsoft.com/en-us/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows

### 3/5

3/5 An online-only file needs an internet connection to open. 'Always keep on this device' downloads it for offline use and takes local space. The same file list can contain files with very different access conditions.

https://support.microsoft.com/en-us/sharepoint/sync/work-with-synced-files-in-file-explorer

### 4/5

4/5 Keeping the cloud copy preserves the content, but cleanup can still undermine the next task. Before a trip, local storage buys access without a connection. For rarely opened files with reliable connectivity, online-only storage may be a better tradeoff.

### 5/5

5/5 A label worth testing beside 'Free up space': 'Keep in OneDrive; internet needed to open.' It answers where the file remains and what opening it requires. Those consequences belong in the cleanup decision alongside the bytes recovered.
