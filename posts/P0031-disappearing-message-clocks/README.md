# P31｜消失消息：24 小时从什么时候算？

2026-11-07 · P0031 · 隐私与默认设置（P27–P33）

**读者价值：** 在跨班交接和定期清理聊天时，判断到期应从发送还是从阅读开始，并区分聊天留存和凭证失效。

**观点：** 相同时长可对应不同阅读机会。若晚读仍有价值，给接收者留出阅读窗口；若重视按年龄清理原聊天，就使用发送起算。转发副本和凭证分别检查。

**证据边界：** 只核查英文官方帮助页的普通聊天计时规则，没有实际操作账号或量化行为效果。案例是设计场景，不是实测。
