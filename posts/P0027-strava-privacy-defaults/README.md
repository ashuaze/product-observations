# P27｜Strava：隐藏路线，不等于收窄受众

- 稳定编号：P0027；原期号：P27
- 日期：2026-11-03（Asia/Shanghai）
- 研究主题：隐私与默认设置（P27–P33）
- 研究问题：产品应替用户预先决定哪些信息被谁看见，又怎样让默认设置的边界可理解？
- 读者价值：把受众、内容遮挡和生效范围拆成独立决策，避免用设置完成率替代理解与保护效果。

## 观点总结

Strava 的地图遮挡与活动受众互不替代，默认值还带有时间范围。减少可见内容不会自动收窄受众；更改未来上传的规则也不意味着旧记录已更新。设计应先围绕私人记录、朋友分享或公开竞赛确定任务，再解释各项取舍。

公开排行榜是重要反例：收窄受众会失去真实功能价值，因此本期不主张所有场景采用同一种私密默认值。建议单独检验用户是否能预测谁看得到什么、哪些旧记录保持原样。

## 证据边界

功能规则来自 2026-11-03 实际打开的 Strava 英文官方说明；成年新账号与地图默认触发时机均有限定。2022 年位置推断研究只作为历史机制证据，未审计现版本、未估计当前泄露率；本次无账号实测或增长数据。
