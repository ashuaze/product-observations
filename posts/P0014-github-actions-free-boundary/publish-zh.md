### 1/4

1/4 免费层不只是在问“送多少额度”，也可能在问“平台愿意补贴什么行为”。

GitHub Actions 把仓库公开性纳入边界，公开产出与私有使用面对不同计费路径。

### 2/4

2/4 原核查规则下，公共仓库使用标准托管 runner 免费；私有仓库先使用套餐额度，启用付费用量后可产生超额账单。

这不是简单按每个用户相同额度划分。
https://docs.github.com/en/billing/concepts/product-billing/github-actions

### 3/4

3/4 大型托管 runner 即使用于公共仓库也收费。自托管虽不收 Actions 使用费，机器与维护仍由用户承担。

“免费”可能止于高阶容量，也可能只是把成本移到别处。

### 4/4

4/4 “补贴公开代码换取生态价值”是定价假设，不是已确认的公司动机。

评估补贴时同时看外部贡献和资源成本。不能把公开性当作普遍的支付意愿：机密项目无法用公开换折扣。
