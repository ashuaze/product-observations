# P0013｜Calendly：免费版限制的不是预约次数

**日期：** 2026-10-20（Asia/Shanghai）  
**研究主题：** 免费与付费边界  
**稿件状态：** 中英文均为草稿，待人工审稿

区分预约量与可复用配置需求，检验免费边界是否对应新增价值。

## 观点总结

- Calendly 免费版支持无限次一对一预约，但只有一个启用中的 Event Type。限制的是可复用模板，不是预约次数。
- “预约很多”与“需要多套长期预约流程”不同：一个模板可以反复使用；两个模板同时开放，即使用量很少也会触及这一限制。
- One-off Meetings 是重要反例：免费用户仍可处理自定义时长、地点的一次性例外，但链接用后失效，改期要取消重建。因此不能写成“不同会议就必须付费”。
- Cal.com 个人免费版提供无限 Event Types 与日历连接，团队排班等进入付费层。这是不同商业边界，不证明谁的转化、收入或体验更好。
- 应检验重复配置负担是否比预约量更能预测付费，而不是把任何高频行为都视为升级需求。
