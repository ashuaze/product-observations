# PagerDuty：确认接手之后，什么时候该再呼叫？

P38 · 2026-11-14（北京时间） · P34–P40 协作交接与责任

**读者价值：** 区分无人接手与接手后失联，决定何时再次叫醒后备。

PagerDuty 分开确认接手与解决状态，也提供可选的接手后超时。比较同一故障里的重复呼叫与失联风险。功能来自官方文档，未实测响应效率。
