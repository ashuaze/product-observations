# P0023｜Instagram 点赞数：一项指标到底给谁看？

**日期：** 2026-10-30（Asia/Shanghai）  
**研究主题：** 习惯设计的收益与副作用；P20–P26 研究周期  
**内容类型：** 案例分析  
**稿件状态：** 中英文均为草稿，待人工审稿

帮助产品经理、设计师与独立开发者，拆开创作者反馈与观看者社会证明，决定计数应该公开、私有还是隐藏。

## 核心判断

1. 点赞数同时服务创作者与观看者。隐藏自己看到的他人计数，与隐藏自己帖子对外显示的计数，改变的是不同的任务和比较关系。
2. 去指标并非对所有人都有相同收益。原稿引用的三周实验同时隐藏多类计数，照片浏览减少，但平均正向情绪与蓬勃感没有显著改善；不能单独归因于点赞数。
3. 应按受众决定计数的可见性，同时检验持续创作、互动质量与比较压力，而非只看点赞次数。
