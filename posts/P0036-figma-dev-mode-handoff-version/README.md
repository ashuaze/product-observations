# Figma Ready for dev：开发该以哪一版为准？

- 原期号：P36
- 日期：2026-11-12（北京时间）
- 研究主题：协作交接与责任（P34–P40）
- 读者价值：在实时稿和约定版本之间做选择，并检查共享变量等依赖是否会绕过状态提醒。

Figma 的交付状态帮助识别部分修改，但已绑定变量的值变化不会触发 Changed。需要明确验收基准时，把约定版本和关键共享值一起记下来；快速迭代则可以继续看实时稿，约定何时需要再次交接。以上是基于官方规则的设计判断，未实测返工率或历史版本的依赖渲染。
