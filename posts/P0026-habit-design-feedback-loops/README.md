# P0026｜习惯设计的四个杠杆：从增长功能到反馈回路

**日期：** 2026-11-02（Asia/Shanghai）  
**研究主题：** 习惯设计的收益与副作用；P20–P26 周期综合  
**内容类型：** 综合判断  
**稿件状态：** 中英文均为草稿，待人工审稿；未记录发布链接

帮助产品经理、设计师与独立开发者，把“培养习惯”拆成可检验的产品选择，区分参与度代理指标与真实用户结果。

## 核心判断

1. 自动播放、通知、进度计分与社会信号，分别改变继续摩擦、提示节奏、进度计分和社会可见性。它们应分别评价，不能合并为一条“参与度提升”的逻辑。
2. 界面能改变被测量的行为，但行为次数增加不一定带来更好的结果。GitHub 连续贡献研究没有测量工作质量；关闭 Netflix 自动播放也没有显著改变两次会话间隔。
3. 反证要求校准结论：通知批量送达和活动追踪器在部分实验或综述中有收益。因此应校准反馈，而不是一律删除反馈。
4. 停止、休息、忽略或隐藏应成为可表达的状态。产品评估应同时关注目标结果、压力和回避行为。
