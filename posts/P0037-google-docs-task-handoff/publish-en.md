### 1/4

1/4 Delete a checklist line in Google Docs and the task it created can still be on someone's to-do list. That makes a useful design question: when a meeting note changes, which commitments should survive?

### 2/4

2/4 For "check this number," assign an action item on the comment next to it. For "send the revised forecast on Friday," a Docs task can appear in the assignee's Google Tasks list. Both options are for work or school accounts. https://support.google.com/docs/answer/12048749?hl=en&ref_topic=9045930

### 3/4

3/4 A task outside the doc is easier to find later. It can also outlive the plan: Google says removing the checklist line leaves the task on the assignee's list unless you delete the task itself. That can be useful if you're just tidying the notes.

### 4/4

4/4 Keep paragraph fixes beside the paragraph. Put work that has to travel in a task list. Then test a change of plan: can the author cancel the task, and can the assignee tell the difference between a deleted note and a canceled commitment?
